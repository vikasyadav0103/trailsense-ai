# Contributing to TrailSense AI

Thanks for considering a contribution. This project is in early development, so focused issues, documentation, model evaluation, and small tested changes are especially useful.

## Ways to contribute

- Evaluate open-weight bird classifiers, licenses, and species coverage.
- Add reproducible model evaluation tests and examples.
- Improve offline-first behavior and privacy documentation.
- Contribute to the Spring Boot API, Python inference service, or frontend as these components are implemented.
- Improve accessibility and outdoor usability.

## Workflow

1. Find or open an issue describing the change.
2. Discuss substantial changes before starting work.
3. Create a focused feature branch.
4. Include tests or reproducible validation steps where practical.
5. Update documentation and explain limitations in your pull request.

## Model and data contributions

Record model source, exact revision, license, preprocessing, and evaluation method. Do not commit large model weights or personal photos without discussion. Never claim offline operation without testing after disconnecting the network.

## Community

Be respectful and constructive. Critique code and ideas, not people.
