# Model selection and weights

No model weights have been selected or committed yet.

Evaluate candidate bird classifiers for:

- License terms for model code and weights.
- Bird species and geographic coverage relevant to intended users.
- CPU/GPU requirements, model size, and startup time.
- Measured performance on representative, legally usable test images.
- Known limitations and common misclassifications.

Before selecting a model, document its source URL, immutable revision, license, preprocessing, and evaluation method. Avoid committing large weights to Git; provide a reproducible download procedure instead.

Open weights do not automatically imply an unrestricted license. Review the actual model and dataset terms.
